# zorkatv.github.io

Сайт ZorkaTV и ссылки, которые открывают приложение (universal links): `/p/<канал>/<начало>`, `/live/<канал>`, `/a/<канал>/<начало>?t=<с>`.

Короткая форма (приложение делится ей с 2026-11-05), например `https://zorkatv.github.io/p/_AlBlQkSyOXw/21Rvc`: канал `ch` + 20 цифр — `_` + число в base 62 (`0-9A-Za-z`), остальные коды как есть; начало в base 62 — 5 знаков минут с 1970 года или 6 знаков секунд, если не на минуте. Старые ссылки (код как есть, Unix-секунды, `?n=<название>`) тоже открываются; `404.html` разбирает обе формы.

## Страница

`index.html` — одна страница без сборки и внешних библиотек: стили и скрипт внутри. Русский текст стоит в разметке, белорусский и английский — в словаре скрипта (ключи `data-i`, для атрибутов `data-ia`). Язык: `?lang=be|en|ru`, затем выбор посетителя (localStorage), затем язык браузера, иначе русский. Тёмная тема по умолчанию, светлая — по `prefers-color-scheme`; движение выключается при `prefers-reduced-motion`.

- `shots/` — скриншоты; что снять для каждого файла, сказано в `shots/README.md`.
- `apple-touch-icon.png` (180 × 180) и `og-image.png` (1200 × 630) нарисованы из `icon.svg`; при смене иконки их надо перерисовать.
- `404.html` оформлен в тон главной; разбор ссылок в нём не менялся.

Проверить локально: `python3 -m http.server` в этой папке и открыть `http://localhost:8000`. Короткие ссылки так не проверить: простой сервер не отдаёт `404.html` вместо несуществующего пути, GitHub Pages — отдаёт.
