# Скриншоты для сайта

Сейчас здесь заглушки с названием места. Замените каждый файл настоящим снимком с тем же именем; разметку менять не нужно. Рамку устройства (корпус, Dynamic Island, сгиб Duo) рисует страница, поэтому нужен чистый снимок экрана из симулятора (⌘S в Simulator) без рамки.

Снимать в демо-режиме: там открытые фильмы и тестовые потоки, нет логотипов и названий каналов оператора. Тема «Тёмная» (кроме `iphone-themes.jpg`), язык русский, статус-бар чистый: `xcrun simctl status_bar booted override --time 9:41 --batteryState charged --batteryLevel 100 --cellularBars 4 --wifiBars 3`.

## Размер и формат

Страница ждёт JPEG такого размера (пропорции экрана сохраняются, отклонение на пару пикселей не страшно):

| Файлы | Размер |
|---|---|
| `iphone-*.jpg` вертикальные | 754 × 1640 |
| `iphone-landscape-player.jpg` | 1640 × 754 |
| `ipad-*.jpg` | 1640 × 1230 |
| `duo-open.jpg` | 1640 × 1154 |
| `duo-tabletop.jpg` | 1154 × 1640 |

Перевод снимка из симулятора (PNG) в нужный файл — `sips` есть в macOS: длинная сторона 1640, JPEG качества 82.

```sh
sips -Z 1640 -s format jpeg -s formatOptions 82 "Simulator Screenshot.png" --out shots/iphone-now.jpg
```

Если пропорции другие (другая модель или снимок не того положения), обновите `width` и `height` у `<img>` в `index.html`, иначе страница при загрузке немного прыгнет.
